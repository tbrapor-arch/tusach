# Data sources and attribution

None of these datasets are stored in this repository. `make data` downloads them at pinned versions into `data/raw/`
(git-ignored), and `make db` builds `data/build/vi.db` locally. A source is added here only after its licence is
checked on its own page; non-commercial sources reach only `make db-nc` (private builds).
