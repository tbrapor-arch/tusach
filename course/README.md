# Course content

Original lessons written by Claude for this course (CC BY-SA 4.0). Northern (Hà Nội) Vietnamese, explained in English.
No lesson is drafted before the owner approves the syllabus and the first word list (`syllabus.yaml`; `make lint`
refuses lessons until then). Format: `docs/REFERENCE.md` and `lesson_template.yaml` (no other file than NN.yaml may sit in `lessons/`). Check with `make lint`.
